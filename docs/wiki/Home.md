# DC Training Log

DC Training Log is a private workout logbook for a pre-authorized owner following a Doggcrapp (DC) exercise rotation. It records exercise assignments, weights, reps, stretches, and logbook results in a phone-oriented web app.

## Scope

The app supports a fixed six-workout rotation, a supplied exercise catalogue, rest-pause and straight-set prescriptions, and timed abdominal holds. It is a personal logbook, not a public coaching service: there is no guest mode, signup flow, coach dashboard, arbitrary workout builder, or calendar scheduler. It records training; it does not establish whether an exercise or load is appropriate for you.

Offline use requires a cached app, a valid verified owner session, and device storage. Unsynced entries and unfinished input drafts are not recoverable from another device. See [Offline and account](https://github.com/mbh-solutions/dc_training/wiki/Offline-and-account) before clearing browser data.
